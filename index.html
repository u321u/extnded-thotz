Questions?

Everything you need to know

Does it send audio to the cloud?

No. Transcription runs on your machine with local Whisper by default. Your audio never leaves your computer.

Do I need Python installed?

No. It's a portable Windows executable — download, run, done.

Does it work in all Windows apps?

Yes. It works in virtually any app that accepts text input. If an app runs as admin, run Extnded Thotz as admin too due to Windows privilege restrictions.

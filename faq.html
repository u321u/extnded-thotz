FAQ

Everything you need to know

Privacy, compatibility, setup, licensing — straight answers to help you decide if Extnded Thotz is right for you.

Does it send audio to the cloud?

No. By default, transcription runs entirely on your machine using local Whisper. Your audio never leaves your computer unless you explicitly enable a cloud backend or AI polish features.

Do I need Python installed?

No. The download is a portable Windows executable. Just download and run it — no dependencies, no install wizard.

Which Windows versions are supported?

Windows 10 and Windows 11. The app is optimized for modern Windows. There are no macOS or Linux builds yet.

Can I change the hotkey?

Yes. Open the settings window and record any key or chord. You can also choose between hold-to-talk and toggle mode.

Does it work in every app?

It works in virtually any app that accepts text input (VS Code, Slack, Notepad++, Chrome, Firefox, Outlook, etc.). If an app runs as Administrator, you'll need to run Extnded Thotz as Administrator too due to Windows' UIPI (User Interface Privilege Isolation).

How much does it cost?

$29 one-time for Extnded Thotz Pro. No subscription, no recurring fees. All current updates are included.

Can I try it before buying?

Yes. Download the free build and use it as long as you want. If you love it, purchase a license. No trial timer.

How big is the download?

The executable is ~22 MB. On first run, it will download the Whisper base model (~145 MB) once.

Is my clipboard safe?

Yes. Extnded Thotz automatically saves and restores your clipboard when inserting dictated text.

Can I cancel mid-dictation?

Yes — press ESC at any time to cancel without inserting anything.

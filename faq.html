Straight answers

Frequently asked questions

Privacy, compatibility, setup, download size — everything you might want to know before picking up a free copy of Extnded Thotz.

Is Extnded Thotz really free?

Yes. It is completely free to download and use — no account, no license key, no upsell, no feature paywall.

Does it send my audio to the cloud?

No. By default, transcription runs entirely on your machine using a local Whisper model. Your audio never leaves your computer.

Do I need Python installed?

No. The download is a portable Windows executable. Run it directly — no dependencies, no install wizard, nothing to configure.

Is there a macOS version?

Yes — download it from the release page. It is a universal build (Intel and Apple Silicon). The app is unsigned, so the first launch needs a right-click and "Open" — after that Gatekeeper remembers your choice.

Which Windows versions are supported?

Windows 10 and Windows 11 (64-bit). macOS 12 and later are supported by the universal build linked in the platform cards.

Can I change the hotkey?

Yes. Open the settings window from the tray icon and record any key or chord. You can also switch between hold-to-talk and toggle mode.

Does it work in every app?

It works in virtually any app that accepts text input — VS Code, Slack, Notepad++, Chrome, Firefox, Outlook, and more. If an app runs as Administrator, you will need to run Extnded Thotz as Administrator too (a Windows UIPI restriction), otherwise the paste is blocked.

How big is the download?

The executable is about 22 MB. On first run it may download the Whisper base model once, around 145 MB, so transcription works offline from then on.

Is my clipboard safe?

Yes. The app saves your clipboard before inserting dictated text and restores it immediately after, every time.

Can I cancel mid-sentence?

Yes. Press ESC while recording to cancel — nothing is transcribed, nothing is inserted.

Why does Windows SmartScreen warn me?

The build is not code-signed yet, so Windows shows an "unknown publisher" notice on first run. Verify the SHA-256 checksum on the download page matches, then click through. This is normal for unsigned portable software. On macOS, the same applies after right-click → Open.
